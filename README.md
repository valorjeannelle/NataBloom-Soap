# 🌿 NataBloom Soap

**NataBloom Soap** est un site web vitrine dédié à la présentation de savons artisanaux et de soins pour la peau. Il permet aux visiteurs de découvrir les différentes créations, de consulter leurs compositions et de passer commande facilement via WhatsApp.

## ✨ Fonctionnalités

- Présentation de la marque NataBloom Soap.
- Affichage des différents savons sous forme de cartes interactives.
- Consultation des compositions et des propriétés des produits.
- Affichage des formats disponibles dans des fenêtres modales.
- Navigation entre les différentes sections du site.
- Accès direct à WhatsApp pour passer une commande.
- Interface adaptée aux ordinateurs et aux appareils mobiles.

## 🛠️ Technologies utilisées

- **HTML5** : structure et organisation du contenu.
- **CSS3** : mise en page, animations et design responsive.
- **JavaScript** : interactions et comportements dynamiques.

## 🚀 Installation et utilisation

1. Cloner le dépôt :

```bash
git clone https://github.com/TON-PSEUDO/natabloom-soap.git
```

2. Accéder au dossier :

```bash
cd natabloom-soap
```

3. Ouvrir le fichier `index.html` dans un navigateur ou utiliser l'extension **Live Server** de Visual Studio Code.

## 📱 Commandes

Les visiteurs peuvent contacter NataBloom Soap directement via WhatsApp depuis le site pour obtenir des informations ou passer une commande.
